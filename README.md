# nash

> このプロジェクトはAIによって生成されました。

**Nomad Anywhere Shell**

nashは、外出先でもシームレスにリモートアクセスできるように設計されたモバイルファーストのSSHクライアントです。

## 特徴

- **モバイルファースト**: タッチインターフェースや小さな画面に最適化されています。
- **動的な接続管理**: 複数のSSHホストを簡単に管理・接続できます。
- **モダンなUI**: React, TypeScript, Glassmorphismデザインを採用しています。
- **堅牢なバックエンド**: Go言語による信頼性の高いSSH接続処理を実現しています。

## 開発

### 前提条件

- Go 1.22以上
- Node.js 20以上
- `air` (バックエンドのホットリロード用)

### クイックスタート

開発環境（フロントエンド + バックエンド）を起動します：

```bash
make run
```

- フロントエンド: http://localhost:5173
- バックエンド: http://localhost:8080

## ビルド

本番用バイナリ（フロントエンドのアセットを含む）をビルドします：

```bash
make build
```

`./nash` としてバイナリが出力されます。

## テスト

ユニットテスト（フロントエンド & バックエンド）を実行します：

```bash
make test
```

E2Eテストを実行します：

```bash
make test-e2e
```

## Storybook

UIコンポーネントを確認します：

```bash
make storybook
```
