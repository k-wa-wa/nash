# AI要約機能 仕様書

## 1. 概要
ターミナルに出力された直近のコマンドとその実行結果をAIが解析し、日本語で簡潔に要約を表示する。

## 2. UI仕様コンポーネント

### 2.1 円形AIボタン（トリガー）
- [ ] **形状**: 44x44px の完全な円形、背景透過（グラスモルフィズム）。
- [ ] **表示位置**: ターミナルエリアの右上（`top: 10px, right: 10px`）。
- [ ] **表示条件**: アプリケーションモード（vim実行中など）以外で表示。
- [ ] **インタラクション**:
    - クリックでオーバーレイの開閉をトグルする。
    - ホバー時にスケールアップ、5度の傾斜、および青色のグロー効果が発生すること。

### 2.2 AI要約オーバーレイ
- [ ] **デザイン**:
    - [ ] `backdrop-filter: blur(25px)` によるグラスモルフィズム効果。
    - [ ] 四方に 12px のマージンを持つフローティングレイアウト。
    - [ ] 角丸 `20px` および強力なドロップシャドウの適用。
- [ ] **アニメーション**:
    - [ ] `transform-origin: top right` に設定されていること。
    - [ ] 出現時: 上部からバウンスしながらフェードインする。
    - [ ] 消失時: 右上のAIボタンに向かって吸い込まれるように縮小・フェードアウトすること。
- [ ] **表示内容**:
    - [ ] 解析中: 「Analyzing output...」とスピナーを表示。
    - [ ] 要約なし: 「まだ要約がありません」と表示。
    - [ ] 解析後: 日本語の要約結果を段落ごとに表示。

## 3. 機能仕様（ロジック）

### 3.1 抽出アルゴリズム
- [ ] **マーカー同期**: `CommandInput` でEnterキーが押された際、その瞬間のターミナル行に `registerMarker` を実行すること。
- [ ] **差分抽出**: 要約トリガー時、設置された最新のマーカー行から現在のカーソル行までのテキストのみを抽出対象とすること。
- [ ] **初回スキップ**: マーカーが一度も設置されていない状態（接続直後のMOTD表示時など）では、`getBufferText` は空文字を返し、要約を実行しないこと。
- [ ] **リセット**: APIリクエスト後は、次のコマンドが入力されるまで以前のバッファをクリア（無視）すること。

### 3.2 要約トリガー
- [ ] **自動判定**: ターミナルへデータが流れてこなくなってから 1,000ms 経過した際に自動実行されること。
- [ ] **閾値**: 抽出されたテキストが 20文字未満の場合は要約を実行しないこと。

### 3.3 設定永続化
- [ ] **SettingsPage**: `/settings` 画面で AI Summary の有効/無効を切り替えられること。
- [ ] **localStorage**: `aiSummaryEnabled` キーに `true`/`false` を文字列で保存・同期すること。

## 4. 検証・デバッグ
- [ ] **コンソールログ**: `[AI Summary] API Request Details` グループ内に、送信バッファの全文と `startLine` / `endLine` が出力されること。
- [ ] **エラーハンドリング**: APIエラー時、コンソールにエラー詳細が出力され、ローディング状態が解除されること。
