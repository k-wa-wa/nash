# ホーム画面 (/) 仕様・チェックリスト

## 1. Available Hosts (接続先リスト)
- [ ] **表示**: タイトル "Available Hosts" が表示されること
- [ ] **データ**: バックエンドから取得したホスト一覧が表示されること (ssh_config準拠)
- [ ] **ローディング処理**:
    - データ取得中、ホスト一覧取得APIのレスポンス待ち状態を管理 (`isLoading`) すること
    - **遅延表示**: 高速なレスポンス時のチラつきを防ぐため、取得に 200ms 以上かかる場合のみスケルトンローダーを表示すること
    - **アニメーション**: リスト表示時にフェードインアニメーションを適用し、スムーズに表示すること
- [ ] **項目**: 各ホストに以下の情報が表示されること
    - `Host` (エイリアス)
    - `User`
    - `HostName`
- [ ] **動作**: ホストをクリック/タップすると、そのホストへの接続を開始しターミナル画面へ遷移すること
- [ ] **エッジケース**: ホスト一覧が空の場合、"No hosts found in ssh_config" というメッセージが表示されること

## 2. Quick Connect (手動接続フォーム)
- [ ] **表示**: タイトル "Quick Connect" が表示されること
- [ ] **入力欄**: 以下の入力項目が存在し、正しく入力できること
    - `Hostname / IP` (必須)
    - `User` (必須)
    - `Port` (数値, デフォルト22)
    - `Password` (任意)
- [ ] **初期値**: 環境変数 (`VITE_SSH_*`) が設定されている場合、初期値として入力画面に反映されていること
- [ ] **動作**: Connectボタンを押下すると、入力された情報でターミナル画面 (`/terminal`) へ遷移すること

## 3. ヘッダー / ナビゲーション
- [ ] **Settings**: ヘッダー右側に設定ボタン（歯車アイコン）を配置し、`/settings` へ遷移できること
